# Project Rules — ChemLab Studio (`virtual lab`)

## 1. Auto-Publish to GitHub on Completed Versions
- Whenever a new feature, milestone, or bugfix version is completed and verified in this workspace, **automatically commit and push** the changes to `origin/main` (`https://github.com/iamjulies/virtuallab.git`) without waiting for the user to ask.
- Before pushing:
  1. Ensure `git` and `gh` are available in `PATH` (on Windows PowerShell, refresh `Machine` + `User` `Path` environment variables if needed).
  2. Run verification (`tests/engine_verify.html` via local server / headless check when engine, species, reactions, or physics files change) and confirm all tests pass.
  3. Increment a monotonic build number using `<version>+build.<N>` (e.g., `virlab_beta_v1+build.3`), update the visible version string in `index.html` (`<title>`) and `src/data/i18n.js` (`vi` and `en` subtitles), and bump `CACHE_NAME` (plus `ASSETS` if files were added/renamed) in `sw.js` to match the new build so PWA/GitHub Pages caching and visible build tracking stay in sync.
  4. Never stage or commit secrets, tokens, or `.env`/credential files.
  5. Use clear Conventional Commit messages including the build tag (e.g., `feat: ... (virlab_beta_v1+build.3)`) and report the `<version>+build.<N>`, commit hash, and live GitHub Pages URL (`https://iamjulies.github.io/virtuallab/`) in the final reply.

## 2. Project Design & Chemistry Invariants
- **Strict IUPAC Nomenclature:** All chemical names, element names, and foreign proper nouns in both `vi` and `en` UI strings (`src/data/i18n.js`, `src/data/species.js`, `src/data/reactions.js`) MUST use official IUPAC English spellings (never Vietnamese phonetic transliteration).
- **Bilingual, Theme & Device Parity:** Every UI addition must support both Vietnamese (`vi`) and English (`en`), `Light` and `Dark` themes (including Canvas rendering contrast), and `Desktop / Tablet / Mobile` responsive layouts.
- **Zero-Build Static / PWA Architecture:** Keep the codebase pure ES Modules + HTML5 Canvas + self-contained CSS with relative `./` paths so it deploys directly to GitHub Pages with zero build step.
- **Metal Ion Flame Test Invariant (`/learn`):** Whenever a new metal ion is added to the simulation, always evaluate whether it has a characteristic flame test emission color; if it does (e.g., `Na⁺` golden-yellow 589 nm, `Ca²⁺` brick-red 622 nm, `Ba²⁺` apple yellow-green 524 nm, `Cu²⁺` emerald blue-green 515 nm), wire it into the Flame Test Loop (`checkFlameLoopInteractions` & burner flame rendering); if it has no characteristic flame emission color, omit it.
- **Complete Researched Species Metadata Invariant (`/learn`):** Whenever adding ANY new chemical species (`src/data/species.js` or `src/data/organic/*.js`), look up verified physico-chemical reference data and populate all applicable fields of the 6-group `PROPERTY-DRIVEN METADATA SCHEMA` documented at the top of `src/data/species.js` (1. Core Identity: `id`, `formula`, `name`, `phase`, `molarMass`, `atoms`, `charge`; 2. Thermodynamics & Phase Change: `cp`, `density`, `meltTempK`, `boilTempK`, `dHFusJ`, `dHVapJ`, `dHCombustJ`, `autoIgnitionK`, `flashPointK`, `partialMolarVolMl`; 3. Phase Stratification & Solubility: `liquidGroup`, `partitionKow`, `vaporPressureAtm298`, `vaporSpeciesId`, `isPrecipitate`, `isPolymer`, `isFat`, `isSoapIon`, `isSoapSolid`; 4. Viscosity & Electrochemistry: `viscosityCp298` / `viscosityRel298`, `molarConductivity`; 5. Optical Spectroscopy & Chromatography: `color`, `visualType`, `renderLayer`, `extinctionRGB`, `opticalCoeff`, `uvActive` / `isUV`, `tlcColor`, `tlcPolarity`, `eluentStrength`, `uvVisBands`, `irBands`, `functionalGroups`; 6. Aroma & GHS Safety: `aromaProfile`, `ghsHazards`) rather than leaving only bare placeholder fields or relying on hardcoded engine ID tables.
- **Evidence-Grounded Prompt Writing Standard (`/learn`):** Whenever drafting, upgrading, or refining an implementation prompt from the user's bug notes/screenshots (e.g., `.prompt/*.docx`), always inspect all referenced screenshot files directly and trace the exact files, line numbers, symbols, and root causes in the codebase first, then produce numbered modules formatted as `<N>/ <Title> (<exact file paths>):` with `• Ảnh tham chiếu:` (preserving every original screenshot path), `• Nguyên nhân hiện tại:` (citing verified code locations and why the bug happens), `• Yêu cầu:` (concrete UI/physics/i18n/5-theme/responsive requirements), and a final `Kiểm chứng & Đồng bộ` checklist (`index.html`, `src/data/constants.js`, `src/data/i18n_*.js`, `sw.js` `CACHE_NAME`, regression tests in `tests/engine_verify.html`, and auto-publish to `origin/main`).
- **Theme Design & Signature Gimmick Invariant (`/learn`):** Every new UI/Canvas theme added to ChemLab Studio MUST synchronously implement all 4 layers: (1) `[data-theme="<id>"]` CSS custom properties plus light/dark badge/utility text contrast overrides in `styles/main.css`; (2) `getThemePalette()` & workbench backdrop/grid contrast in `src/canvas/vesselRenderer.js` and `src/canvas/workbench.js`; (3) selector registration and bilingual `vi`/`en` keys in `src/ui/environmentBar.js` and `src/data/i18n_*.js`; and (4) a unique **Signature Interactive Canvas Gimmick** tied to live lab physics/chemistry events (never duplicating existing gimmicks: `olivia` heart stopper/pipette, `petal` reaction petals, `ctrl` CRT pixel flame, `sos` shatter ocean waves). Verification must cover **all registered themes** (do not hardcode "5 themes").
- **Simple Organic Bottle Structural Formula Invariant (`/learn`):** On reagent bottle labels (`src/canvas/reagentRenderer.js`), any simple organic reagent with `<= 1` aromatic ring (excluding macromolecules, polymers, proteins, and long-chain triglycerides such as `triolein`, `sucrose`, `starch`, `cellulose`, `albumin`) MUST render a crisp vector structural/skeletal formula (`etoh`, `methanol`, `ch3cooh`, `hcooh`, `hcho_37`, `glycerol`, `glucose`, `fructose`, `glycine`, `benzene`) rather than a generic decorative icon.
- **Deep Chemical Research Invariant on Adding Species/Elements (`/learn`):** Whenever adding a new element or compound to the lab, always research and implement complete verified reference data covering: (a) standard physical properties (crystal lattice, `density`, `meltTempK`, `boilTempK`, magnetism/Curie temperature if ferromagnetic, conductivity, color/appearance); (b) the full chemical reactivity matrix & conditions (`O2`/`S`/halogens under heat, cold water vs red-hot steam, non-oxidizing acids, oxidizing acids including cold-conc passivation + thermal depassivation, alkali stability, standard reduction potential `E°` & metal displacement series); and (c) derived salts, precipitates, coordination complexes, industrial purification equilibria, and catalytic roles interacting with existing lab reagents.
